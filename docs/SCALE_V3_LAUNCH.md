# Fresh six-world comparison after startup qualification

The full study is registered in
[scale-preregistration-v3.json](scale-preregistration-v3.json), byte-identical to
the private campaign manifest. Its raw SHA-256 is
`ca6a3d2b890ebdf1a5142dbccd2d019b60179b5d8e61946725b33b743eb0b229`.
Preparation used code commit `b829c4ca0b605e74e3eff9233b0dbf03cf0c435c`.
The manifest fixes 38 execution sources and 31 registration, supervision, audit
and reporting helpers before any world is dispatched.

Both no-learning Hermes and pinned SkillOpt-Sleep run for seeds 211, 307 and
401. Every world contains four enterprises, twelve employee agents, eight
consumers and one agency. The three seed cohorts contain 75 distinct Persona 8B
records; each pair receives identical cohort bytes. All six worlds start fresh.
These are reused development seeds and cohorts, not held-out confirmation.

Each world has twenty action days and two settlement days. Native MiroFish/OASIS
actors retain their timeline and business state while responding to competition,
policy changes and fictional geopolitical conditions. Hermes executes employee
work in bubblewrap. The declared skill-transfer comparison starts each work
attempt with fresh private agent state and the currently deployed employee
skill; both arms retain the same permitted actor history, notes and business
state. The no-learning arm retains its seed skill.

SkillOpt keeps T2/V2/K2, four candidate edits and boundaries on days 3, 7, 11 and
17. Day 3 remains ineligible under the existing feedback-release rules. An
accepted edit first becomes available on the following day. Both arms and all
replays use the same nonstreaming transport and startup observations. Task
rubrics, adoption rules and compute limits have not been relaxed.

The endpoint requires all six completed, audited worlds and three complete
pairs. Fixed-demand fulfillment before the work horizon is primary, with 240
fixed commitments per world. Native-demand fulfillment, synthetic utility,
adoption and prospective skill exposure remain secondary. No minimum adoption
count or positive effect is required. Failed prefixes or surviving pairs cannot
replace the registered comparison.

The campaign runs three fixed pair waves with at most two worlds active. A
shared scope limits the complete process tree to four CPU equivalents, 12 GiB
memory, 512 tasks and zero swap. Each world retains a 24-hour ceiling; the
complete execution ceiling is 260,310 seconds, plus 180 seconds for outer
cleanup. These are limits, not completion forecasts. The shared scope provides
neither per-world resource fairness nor guaranteed I/O isolation.

The planned maximum is 1,440 online sessions, 108 eligible learning epochs and
1,296 target replays. Employee/optimizer caps total 44,640 physical calls and
792 million charged or reserved tokens. Up to 3,972 contracted actor interviews
have separate receipts. Bootstrap/social inference, possible server-orphan
usage, currency and all-in cost remain outside that accounting scope.

The five prerequisites bind historical actor capability, historical employee
capability, duration observations, the
[nine-slot native startup qualification](HERMES_STARTUP_SCOPE_V3_OUTCOME.md), and
the [current-source compatibility review](scale-v3-employee-source-compatibility-review.json).
The historical employee audit is reconstructed using its original committed
sources and the exact reviewed correction. The fresh startup result is a
component qualification, not a provider or long-horizon reliability guarantee.
All five read-only checks passed before registration; the launcher repeats them
before dispatch. The [independent registration review](scale-v3-registration-review.json)
verified the frozen sources, all five prerequisites, paired cohorts and current
installation before any execution intent existed. All 163 offline tests passed and independent implementation
reviews completed before the sources were frozen.

See the [execution guide](SCALE_V3_EXECUTION.md) for the one-shot command, private
installation requirements, cleanup ownership and completed-study reporting.
Registration alone does not mean the campaign has started or completed. No
learning gain is claimed by this registration.
