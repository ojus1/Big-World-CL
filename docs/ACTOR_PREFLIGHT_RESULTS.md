# Native actor contract capability result

The [registered four-role preflight](actor-preflight-registration-v1.json)
completed in 63.18 seconds, including native bootstrap and cleanup. Actual
Persona-backed MiroFish/OASIS actors for employee, enterprise, government and
consumer each returned the exact declared JSON fixture through the hosted model
and patched native interview path. No repair was required.

All four contracted interviews had complete usage receipts: four logical
requests, four physical requests and 5,721 measured tokens, with no unknown
interview usage or outstanding output reservations. Schema, fixture, actor,
logical request, fresh database trace, output cap and deadline checks passed.
The worker and backend exited with code zero, and the separately launched native
process exited. The backend log records one native process-group termination
event on its SIGTERM path, with no logged SIGKILL escalation. No additional
supervisor native fallback signals were required; that supervisor field alone
does not describe all signals used by backend cleanup.

The [safe observation](actor-preflight-observation-v1.json) records per-role
token counts and hashes bound to the immutable registration, private summary
and private evidence inventory. The inventory covers 22 preflight files and 29
native upload files, including claims, receipts and SQLite evidence. Prompts,
responses and persona attributes remain private. The per-role receipt hashes
use the declared canonical JSON encoding; they are distinct from the raw native
receipt file hashes in the private inventory.

This validates native component capability on this provider and exact source
revision. It establishes neither business-decision quality nor learning gain
nor long-horizon reliability. Graph generation and bootstrap/social model use
remain outside the interview meter; 5,721 tokens is not the complete environment
cost. The active scale-v1 worlds and their execution code were not changed.

The remaining preflight work includes actual Hermes file/tool execution with the
selected employee transport and duration observations needed to budget the full
six-world follow-up. No old and new worlds will be combined into its endpoint.
