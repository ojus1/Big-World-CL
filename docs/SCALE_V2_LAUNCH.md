Both no-learning Hermes and pinned SkillOpt run for each of seeds 211, 307 and
401. Each fresh world contains four enterprises, twelve employees, eight
consumers and one government agency, with persistent business/actor state,
twenty action days and two settlement days. The seventy-five distinct Persona

reuses the complete development cohort set; it is not held-out confirmation.

rules and initial skills remain fixed. Accepted skills first become available
on the following day. Both arms select the same actor JSON contract and native
nonstreaming employee transport. No new request retries or uncertain-world
resume are introduced. All six worlds and all three complete valid pairs are
required; positive gain or any minimum adoption count is not required.

Each world has an explicit 86,400-second execution ceiling. At most six worlds
run concurrently. The [reviewed duration evidence](SCALE_HORIZON_RESULTS.md)
supports this as a finite operational allowance, with no completion forecast.

attempts, 108 epochs, 1,296 learning replays, 44,640 employee/optimizer physical
calls and 792 million charged tokens across the campaign. Contracted actor
interviews are metered separately; bootstrap/social inference and all-in cost
remain outside that meter. World cleanup, service cleanup and service startup
have separate frozen limits of 120, 30 and 120 seconds.
